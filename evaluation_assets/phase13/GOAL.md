# MyRobot Phase 13 长期自主研发目标与验收标准

## 1. 任务背景与核心使命
- **机器人类型**: MyRobot 双足轮足混合机器人 (22.0 kg, 6 DOF: 4 腿部关节 + 2 轮端电机)
- **当前最佳基准 (Champion v4)**: `evaluation_assets/phase8b/models/phase8b_m10.pt` (SHA256: `b92fba14e73e803d8b9a736cdb7213eb3b217c5c87122aa2d1935751f940e9e9`)
- **核心问题**: 现有演示与评测最高运动速度约为 0.20 m/s，无法满足更高机动能力需求。
- **终极使命**: 让 MyRobot 在保持原有静止自平衡、原地深蹲、高度调节、转向与制动等核心优势技能的前提下，突破速度上限，实现标称高度 0.50 m/s 稳定前向巡航与可靠综合运动控制。

## 2. 最终验收标准 (Acceptance Criteria)

### 目标 A：提高运动速度 (首要指标)
1. 机器人能在标称高度约 0.398 m 下稳定达到 0.50 m/s 前进巡航。
2. 实际速度真实跟踪目标（不只是命令设为 0.5 m/s 而实际滞后在低速）。
3. 稳态巡航阶段平均绝对速度跟踪误差 $\le 0.05\text{ m/s}$，且至少 90% 稳态采样时间内满足误差在 $\pm 0.05\text{ m/s}$ 范围内。
4. 持续稳定巡航至少 5.0 秒。
5. 在 0.2, 0.3, 0.4, 0.5 m/s 之间能够平稳加速与减速。
6. 实现至少 0.30 m/s 的稳定后退能力。
7. 不以短暂峰值速度作为成功依据。

### 目标 B：保持基础控制能力 (底线防退化)
1. 原地深蹲 (0.36m) Joint% 不低于 85.0% (Champion v4 达标率 88.8%)。
2. 静止自平衡站立 Env% 不低于 80.0%。
3. 21 工况 Global Joint% 不低于 Champion v4 超过 1 个百分点 (基线 66.52% -> 底线 $\ge 65.52\%$)。
4. 21 工况 Global Env% 不低于 Champion v4 超过 2 个百分点 (基线 63.24% -> 底线 $\ge 61.24\%$)。
5. Sequential Env% 不低于原始基准超过 3 个百分点 (基线 68.36% -> 底线 $\ge 65.36\%$)。

### 目标 C：实现可靠的动态操作
1. 静止平稳起步 -> 加速至 0.5 m/s 巡航 -> 高速平稳减速并停车保持平衡。
2. 适当速度下平稳左右转向与恢复直线。
3. 常规运动速度下平稳下蹲与挺起。
4. 前进与后退顺畅切换。
5. 连续复合运动序列全流程稳定存活，无隐式环境重置。

### 目标 D：安全与物理约束
1. 正式验证样本无倾倒与失控 (Survival rate = 100%)。
2. 真实轮端力矩饱和率 ($\ge 6.95\text{ Nm}$) 原则上 $\le 2.0\%$。
3. 无持续严重关节超限。
4. 真实 teleop 键盘控制可稳定复现。
